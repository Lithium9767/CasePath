# P4-v1 升级接入

## 本次实现范围

- A/C：独立 BM25 与向量列表进入加权 RRF，再融合原有图通道；保留分项分数。
- B：历史条件不因候选规则变化丢失，历史回答证据保留，新事实参与其他条件投影。
  LLM 纠正同一事实的词法映射不再制造事实冲突，不同事实支持/反对才聚合为冲突。
- E：在固定规则/案例候选池模拟满足、不满足、不知道，使用一致的回答似然与贝叶斯
  后验计算预期熵减少和期望名次变化，再结合规则缩减及成本。模拟不调用 LLM/数据库。
- 校准：提供独立标注集拟合的单调分段校准器；没有标注集时明确保留未校准分数。

## 独立 embedding 配置

保持现有聊天模型配置不变，另在本地 .env 配置（不要提交 Key）：

```text
CASEPATH_EMBEDDING_API_KEY=自己的embedding密钥
CASEPATH_EMBEDDING_BASE_URL=供应商兼容接口地址
CASEPATH_EMBEDDING_MODEL=实际embedding模型名
CASEPATH_EMBEDDING_REVISION=本次固定的模型版本标识
CASEPATH_EMBEDDING_DIMENSIONS=实际返回维度
CASEPATH_EMBEDDING_TIMEOUT_SECONDS=30
CASEPATH_EMBEDDING_BATCH_SIZE=32
CASEPATH_VECTOR_INDEX=data/derived/vectors.json
```

配置索引路径表示明确启用向量：缺配置、缺索引或版本不符会失败，不静默降级。
不配置 CASEPATH_VECTOR_INDEX 则仍使用原 BM25＋图基线。

```powershell
# 这一步会发送检索文本并消耗 embedding 额度，请先确认数据许可和账户配置。
uv run --env-file .env python scripts/build_vector_index.py
# 启动时只校验/加载索引，不自动为全部文档调用模型。
uv run --env-file .env uvicorn casepath.api.configured:create_configured_app --factory
```

规则和案例分桶存储：object_id、text_sha256、vector；文件头固定发布版本、目录版本、
模型、模型版本与维度。使用原有检索文档，不把输出角色作为索引文本。
规则/案例或模型版本变化后必须重新建索引；查询模型必须与建库配置一致。
当前是本地精确余弦检索，适合现有数据量，不是 Neo4j 向量索引或 ANN。

## 验收边界

自动测试采用确定性 embedding 替身验证“无词面命中仍由向量补回”、RRF 通道归属、
维度/版本/覆盖率守卫和失败路径。它不是对真实模型语义质量的证明。
部署后仍需用选定真实模型测试同义表达召回、延迟及费用。

追问似然采用工程默认值：明确条件 0.65/0.05/0.30，未知条件 0.35/0.35/0.30；
UNKNOWN 对全部候选概率相同，不被算成新增事实证据。该指标是候选证据模型中的信息增益，
不是裁判结果的信息增益。分化模块 D 的历史启发式字段没有冒充本次模拟指标。
样本不足、案例角色不足仍报告降级；本次没有新增人工金标准。
置信度校准只能在独立开发/校准集拟合，通过工厂的 calibrator 参数注入；未默认训练。

前端、已有 CORS/API 改动和解释展示改动不在本次修改范围。
