# 模块贡献诊断实测

本轮为探索性诊断，读取线上配置的 embedding、Neo4j 和 LLM；不修改图或索引。

## A/C 检索消融

13个固定关系主题查询、156案例，按每路规则10/案例30候选、最终案例池20运行生产检索与角色选择。所有qrels ID确认在库内。查询没有预填请求类型，因此该通道可能为空。使用相同通道结果缓存比较，非耗时实验。

|配置|Recall@5|Recall@10|Recall@20|nDCG@10|
|---|---:|---:|---:|---:|
|BM25|0.3537|0.5890|0.8045|0.7113|
|BM25+向量|0.4180|0.6816|0.9059|0.8171|
|BM25+向量+图|0.3574|0.6805|0.9059|0.7292|
|上述+查询扩展|0.3670|0.6902|0.9059|0.7427|

向量在该组上有增益；图没有提高Recall@20并降低前排排序质量。不得据此宣称所有图检索无效。结果是A种子选择与C共同变化的下游案例评测，不是独立A规则准确率。

限制：标签源于关系类型，生产文本含案由/关键词，存在标签辅助。不是纯事实文本检索评测；未标注案例被视为不相关可能低估其它相关候选。没有B投影输入，不能评价条件角色重排贡献。扩展采样在规则/案例请求分别生成（context对象不同），不是生产单轮复用策略的精确消融；full_expansion只作额外探索，不用于严格归因。没有独立规则gold。

## B 账本消融

固定前6条历史投影状态，不加新事实；控制组只清空projection_ledger。账本组6次重放共0次模型调用、0次状态变化；清空组6次调用、3个样本出现状态变化。该结果证明重复处理成本和重解释波动，不证明原标签正确；部分原状态本身可能存在误判。不能把状态变化全称为错误。

## D/E 与 A用途范围

decision_sensitivity.json 对20条冻结状态保留完整候选列表，比较去掉D输入或去掉A用途范围的候选变化。只执行生产候选选择，不调用E生成，因此不能当作追问质量消融。原20条金标准有缺陷，本轮不据此评分。
