# P3 民事案例数据

- `cases_l1.jsonl`：上游 `legal-rag` 数据中经 `case_category == 民事` 筛选的 45 件案例。
- `cases_deep.jsonl`：服务合同主题的深度结构化候选案例。
- `additional_cases.jsonl`：从最高人民法院公开典型案例中补充的 6 件民事案例。
- `manifest.json`：数据数量、来源和产物清单。

补充案例仅保存不泄漏检索结果的 L1 摘要。案号、法院或裁判日期在最高人民法院汇编页未明确披露时保留为 `null`，不得推测填写。其民事属性依据最高人民法院“人民法院贯彻实施民法典典型案例（第一批）”及对应民事案由、民法典条文指引核验。
